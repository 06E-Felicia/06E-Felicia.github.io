## 修正与受控验证

- 补给路径比较沿途可用湿度、能量及水量，避免停留在被邻近列车耗湿的最近入口。候选入口之后仍检查整段上游路径，保留有限水量账本。
- 新生根部侧向入口最大约 17 km，既有列车可使用约 35 km 内的连通暖侧入口；更远路径平行于季风，防止大角度直线绕过宽冷池。受控断供测试分别验证新生和既有列车的可达范围、深冷池阻挡及浅自身冷池供给。
- 移动单体实际越岭后下降会削弱强回波，即使平滑山脉走向与风向平行也适用；平坦地形不受此项抑制。
- 凤凰山东侧混合海岸格点增加相邻大陆迎风山脚识别。113.58°E、22.30°N 样点抬升准入由 0 恢复至约 0.224；北侧背风坡及相邻海面仍为 0。
- 主季风角度 15–75° 回归通过：24 个种子逐小时检查 72 小时，开场位置及转向时间不同。此角度为向东轴起算的去向角，对应气象来向 195–255°；局地风场另受地形和冷池影响。
- 默认图层为西南季风 / 街道预警。熬夜且未补作业后红暴得 666 分，睡觉后红暴仍为 1000 分。写作业（含补作业）后红暴得 0 分、字幕为“不赌就是赌自己输”。三天最高 3000 分，提前结算和时刻边界回归通过。
