# JPRail 数据

页面为根目录 `JPRail.html`，依赖项目自带 Leaflet、MapLibre GL JS 5.24.0 和 maplibre-gl-leaflet 0.1.3，无需 npm 构建。依赖版本和许可随 `assets/vendor/` 保存。

- `network.geojson`：597 个运营商/线路组，地理几何来自日本国土交通省 [N02-25](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N02-2025.html)，基准日期 2025-12-31，CC BY 4.0。合并同运营商、线路、种别并简化。
- `network-detail.geojson`：同样 597 组的原始精细轨迹，约 8.6 MB；不作几何简化，不用曲线插值补造轨迹。10 级起按需加载并缓存，低于 10 级恢复概览；精细模式仅渲染视野及周边的线路组。坐标保留七位小数不代表实测精度。近铁奈良线的坐标数由概览的 90 个恢复至 474 个，避免放大概览简化误差。
- `grades.json`：等级来源与匹配依据，来自 [Geofabrik Japan OSM extract](https://download.geofabrik.de/asia/japan.html) 的命名铁路标签。按标准化运营方/线路名归并；缺标签或有明显冲突时保留未分类。新干线还使用 N02 的新干线种别。它是线路级参考，不是逐股道或 JR 票价制度的干线/地方交通线分类。包含 OSM 衍生的等级数据库按 ODbL 提供。
- `operator-colors.json`：112 家非 JR 普通铁路运营主体的颜色、官方／替代参考来源与核对日期；另含 JR 普速统一橙黄色、新干线统一红色、运营方别名与混合公司的线路排除项。82 家沿用官网标识参考色，19 家采用线路图、铁路服务页或注明来源的第三方参考色，11 家东京及近郊私铁采用保留原参考色与来源的地图辨识调整色，不宣称所有 HEX 均为官方企业 RGB。
- `japan.geojson`：日本地理轮廓，来源 [Natural Earth 1:50m](https://www.naturalearthdata.com/about/terms-of-use/)，公有领域。不含任何铁路，确保隐藏线路不会从地理底图透出。
- `streets-style.json`：白色街道底图的本地样式，基于 OpenMapTiles Positron 修改，许可见 `STREETS-LICENSE.txt`。在线加载 [OpenFreeMap](https://openfreemap.org/) 矢量瓦片、字形及 OSM 地名；删除铁路／公共交通线条、车站符号与底图铁路标注，防止未匹配铁路从底图透出。地理轮廓仅在底图尚未就绪或连接失败时作为后备。底图状态与重试入口在地图左下方。
- `stations.json`：N02 同源 9,482 个车站位置记录，同名但不同运营公司/线路可能保留多条。
- `passes.json`：55 个产品记录：此前 54 个外国游客产品加 2026-11-13 核对的青春18车票，51 个现行／已公布产品、4 个停售/季节结束记录，附时长、资格、售用期、列车限制、成人普通车厢日元票价及官方链接。所有现行产品覆盖其全部有效天数／小时类型；53 个产品有核实金额，两款停售产品注明无可核实的现行售价，不以零元代替。价格含核查日期及来源；JR 全国、北海道和九州的购买渠道价差另注。关西 LITE 已更新为 2026 冬季发售版本。目录并非国家统一票券数据库，不能保证穷尽新增、临时和渠道限定产品；未明确的条件不作确定推断。

## 显示与过滤

未选择 Pass 时隐藏右侧详情栏，桌面地图延伸至页面右侧；选择 Pass 后恢复详情栏与原三列布局，再按当前地图尺寸定位范围。清除选择或收起详情后恢复宽图，可点已选票券重新打开。960 px 及以下的详情位于地图下方，可收起，不覆盖地图。电脑端采用视口高度，移除工作区 1100 px 高度上限；目录和详情在各自栏内滚动，不在页面底部留下空白。

Pass 为单选，选择另一张后替换原选择；只给其匹配范围保留原色，其余本地线路以浅灰作参考。线路浏览与 Pass 独立：操作任一线路筛选即清除 Pass 与详情；选择 Pass 则清除全部线路条件。运营方可搜索并多选，包含六家 JR、112 家非 JR 普通铁路主体及分组全选；运营方内部取并集，再与线路等级、本线归组、都市圈取交集。同公司兼营的地铁、路面电车、新交通、钢索等线路不进入公司的普通铁路筛选结果。无运营方筛选时保留原有设施和票券权益；空交集没有彩色线路，保留浅灰参考线并显示无匹配提示，不恢复全国线路原色。“三国芦原線”这一源数据运营方别名归入えちぜん鉄道，几何和 Pass 选择器仍保留原始身份。

按用户批准，线路筛选和Pass选择都显示浅灰参考线：`#A3ADB7`、不透明度0.60（透明度40%）。独立Canvas将现有网络画在底图之上、匹配段之下，匹配轨迹以原色不透明覆盖；近距离沿用原始精度与视野缓存。灰线不参与匹配统计、权限判断、站名池、局界判断或线路点击，图例明确灰线仅作参考。未选择任何条件时不启用灰色底层，恢复原全图配色。

普通铁路采用同一套颜色函数：JR 六家公司普速统一橙黄色 `#FF8100`，新干线按 N02 新干线种别统一红色 `#FF0C00`，私铁按 `operator-colors.json` 着色；公司名中含“高速”或线路有地下区间不自动判为地铁。筛选分类另见 line-filters.json，JR 本线与地方／其他线均为橙黄色，颜色不表示等级。普通线路宽 3 px，新干线宽 4 px；选 Pass 后匹配段颜色、线路身份和宽度保持一致，其余线路以浅灰参考线显示。

东京及近郊 11 家颜色过于接近的私铁，使用本页另选的辨识显示色；原参考色和官方来源保留在 `referenceColor`、`referenceBasis`、`source`，调整色不冒充公司官方色。概览、精细线路、Pass 范围、公司筛选、图例与弹窗沿用同一套颜色解析。

黑白标识公司的替代色来源逐项保存在颜色数据中，其中部分引用其他地图的私铁红／第三部门黄绿色类别；这些 HEX 是本页的屏幕参考值，不冒充企业官方色值，也不复用第三方地图几何。地图图例只列出当前匹配线路，长列表在图例内滚动；点击线路可查看配色参考来源。地铁、路面电车、单轨、新交通、钢索缆车没有新增公司颜色，保留原有等级颜色。在线设施原图继续使用 OpenRailwayMap 自身图例，不能被本页公司颜色替换。

在线详细设施原图是 [OpenRailwayMap 标准瓦片](https://wiki.openstreetmap.org/wiki/OpenRailwayMap/API)，按当前视野加载、不批量下载，仅在无 Pass、无线路筛选时可开启。全国视野保留客运参考线，放大至 6 级以上时由设施原图替换，避免低缩放级别无瓦片而空白。筛选时关闭并禁用该图层，防止原图自身配色覆盖本页的匹配／灰色参考规则。原图设施完整性和运营状态依赖 OSM 实际收录及更新，地图版权归 OpenStreetMap 贡献者，适用 [ODbL](https://www.openstreetmap.org/copyright)。

## Pass 范围精度

按用户确认，Pass 选区仍为**示意**：按运营方、线名、种别与区域框筛选/裁切 N02 几何。不能据此推断每站、每种列车、座席、直通公司和进出次数均适用。部分第三部门特例未绘制；附带地铁、巴士、轮渡只作文字说明。数据中的明确截止日期只在已核实官方信息时填写。

近铁 1 日券、札幌－登别、札幌－富良野、富士山－静冈及北陆地区券另保存 `railSections` 起讫区间；`pass-ranges.json` 和 `pass-ranges-detail.json` 沿铁路图寻路，分别配合两档几何，避免用区域框代替已核实的指定区间。仍不代替官方完整票券条件。北陆地区券按官方图保存 7 条 JR 区段与 3 条第三部门条件通过区段，新干线到黑部宇奈月温泉，不到上越妙高；关西・北陆券用 `railOverrides` 仅替换北陆新干线为敦贺—上越妙高，其他匹配范围不变。

`passes.json` 中的 `stationPins` 保存官方范围来源及关键站。`boundary` 用于明确边界／起讫站（地图与按钮只显示站名），`restriction`（限）用于重要限制站，`gateway`（关）仅为区域门户／换乘提示，不把门户站推定为适用边界。选中 Pass 后这些站名在进入视野时不受缩放级别和普通站名密度限制；它们不是完整边界站清单，详情提供官方范围链接。边界站采用加粗站名和绿色圆圈；`company-boundaries.json` 从 N02 归纳 14 个 JR 公司运营接口。只要当前匹配的运营方、线路和种别的实际轨迹到达该已知接口，就以独立蓝色菱形标注：大地图、跨局 Pass 和单公司筛选均可显示。它不是票券边界；真正以局界为票券外缘的点仍另保留票券边界圆圈。地图仅显示站名，局界性质及涉及的线路在提示、弹窗和详情说明，不把矩形裁切点推定为新局界。

## 更新与验证

原始下载包及中间文件应置于每次任务独有的系统临时目录，生成后删除，不进入项目。

```sh
python3 development/scripts/build_jprail_network.py /临时路径/N02-25_GML/UTF-8
python3 development/scripts/enrich_jprail_grades.py /临时路径/japan.osm.pbf
python3 development/scripts/build_jprail_detail.py /临时路径/N02-25_GML.zip
python3 development/scripts/build_jprail_metro_ranges.py
python3 development/scripts/build_jprail_boundaries.py
python3 development/scripts/build_jprail_pass_ranges.py
python3 development/scripts/build_jprail_pass_ranges.py --network assets/data/jprail/network-detail.geojson --output assets/data/jprail/pass-ranges-detail.json
python3 development/tests/test_jprail.py -v
```

生成脚本需要 Shapely、NetworkX，等级脚本还需要 pyosmium；网页本身不需要。页面通过 HTTP/HTTPS 访问（GitHub Pages 或本地预览），不要求离线运行。更新票券时覆盖当前 JSON 并核对官方产品页与售停公告。

## 独立线路筛选（2026-11-14）

`line-filters.json` 保存28组按正式名称整理的JR本线、10个转交后的线路组、11组都市圈及官方归组参考；`jprail-filters.js` 负责筛选与多选菜单，`metro-ranges.json` 保存以车站收尾的两档都市圈几何。原始 N02 几何、OSM 等级标签、票券范围与颜色数据未改。

- 新干线：沿用现有N02种别与青函共用区间显示规则。
- 本线：按正式路名归组；跨JR公司的东海道、中央、山阳等合并展示。北陆含JR西日本与Hapi／IR／爱之风／日本海翡翠，信越含JR东日本／信浓两线／妙高跃马，东北含JR东日本／IGR／青之森，鹿儿岛含JR九州／肥萨橙铁道。现运营方和颜色保留，不补画废除区间或虚构连线。
- 地方／其他JR线：其余JR普速线，含都市通勤线。这是用户选定的路名分类，**不是JR票价制度的干线／地方交通线**，也不等同于OSM的main／branch。
- 私铁线：按当前普通铁路运营方筛选，含第三部门；因此接收的原本线路段同时可属于“本线”和“私铁线”。私铁自有的本线仍列在私铁中。

都市圈包括首都圈、京阪神、中京、札幌、仙台、新潟、静冈／滨松、冈山／仓敷、广岛、北九州／福冈、熊本。都市圈不将新干线计入彩色匹配及匹配数量，但保留浅灰参考、原始与都市圈车站资料以及搜索；站名按当前匹配线路的显示规则呈现，不因保留资料而把新干线误列为可乘范围。退出都市圈后可恢复新干线筛选或Pass原范围。先按数据文件明示的中心车站与公里半径并集选站，保留范围内车站之间的完整实际站间路径；页面显示定义，这是本页铁路浏览范围，不冒充官方通勤圈、行政区或票券／IC卡范围。`build_jprail_metro_ranges.py` 将站点投影到同运营方、同线路的原轨迹，以范围外车站断开拓扑，再保留连接至少两个范围内车站的块切树子树，保留真实平行路径、分支和缺口；不会在半径线上截断或补直线。概览由同一精细几何简化，外缘端点不变。显示车站采用该轨迹投影位置，区段收尾站优先显示普通站点与站名，不冒充Pass边界。

链接可恢复多个运营方、线路等级、归组及都市圈；多数公司被选择时用分组与少量排除项缩短URL。非法公司／归组被忽略。“全部线路”及“清除筛选”清空所有条件并恢复初始取景。多选菜单搜索不会清掉已勾选公司，Escape关闭菜单；菜单与结果列表不随展开推挤地图。

## 地图操作与车站名

初始视野紧贴北海道、本州、四国、九州，采用分数缩放，减少整数级别取景的多余留白。“全部线路”按钮清除当前 Pass、运营方／等级／本线归组／都市圈筛选、设施原图与车站定位，关闭详情列，然后用与初次进入页面相同的取景参数恢复全国线路和初始比例尺；普通窗口尺寸调整只重算视野，不会调用清除选择逻辑。全国取景使用一次重置定位，避免多次复位或移动端尺寸变化累计像素舍入偏差。不提供单独冲绳按钮；冲绳可拖动或搜索车站定位。`jprail-camera.js` 每次按钮操作缩放 0.25 级；滚轮单次手势按输入量缩放 0.05–0.2 级，55 ms 收集首段输入，180 ms 内的惯性尾部归入同一手势，不追加多次动画。每个按钮请求只执行一次缩放，提前预留 Leaflet 下一帧才启动的动画，避免误判空闲。定位与范围请求会等当前动画结束执行，遵循系统减少动态效果设置。

`jprail-stations.js` 使用 Canvas 绘制站点和名称，缓存排序及文字宽度；缩放期间沿用画布变换，结束后重绘，减少整库排序带来的卡顿。站名候选位置同时避让其他文字与当前匹配铁路的实际线段，避免白色描边和关键站名底框遮住轨迹、产生假断线；远移标注用细引线对应站点。全国概览优先显示人工整理的主要城市门户与换乘枢纽（不是客流量排名），区域视野按文字碰撞逐步增加车站；16 级起显示视野内全部本地客运站名。与 Pass、等级及运营方筛选保持一致，同名近邻位置避免重复文字；上述常驻关键站另作优先显示。数据仍以 N02 记录为准，不能代替实时运营公告。

主要枢纽及区域大站在低于 12 级的概览／区域视图采用深色双圈（外半径 5.4 px）与 700 字重站名；12 级及以上恢复此前的普通站点圆点、600 字重主要站名和逐级增加的小站名，16 级起显示当前视野全部车站。缩小回 12 级以下重新显示枢纽双圈；目前人工显示名单为 78 站，表示地图显示优先级，不是官方等级或客流排名。主要站符号仅从当前匹配的车站和已核实的 Pass 关键站中取点，不自动成为票券边界。概览名称拥挤时仍保留站点符号，站名避让普通文字、铁路和地图控件；概览中同一站多线路位置合并一个符号，近距离恢复原有位置去重规则。同名异地的高松、福岛、郡山、大宫、福井、神户、松山、小仓、长崎按既有 N02 坐标限定，避免误标。Pass 边界绿色圈和常驻名称仍独立显示并优先布局。

Pass 边界／铁路端点的内圈与外圈在同一车站 Canvas、同一坐标和同一缩放变换中成对绘制，不再由两个绘图层分别移动。圈形保持既有半径及公司局界虚线含义；透明交互目标只负责原有的悬停提示与点击详情，不再另画可见圆圈。真实边界标记优先于概览枢纽双圈，两种含义不叠成额外圆圈。

底图不显示日本国名：三个国家标注层按 ISO 及日／英名称排除日本，其他国家名称不受本项修改影响。五个城市／乡镇等 place 标注层的 `maxzoom` 从 13 下调为 11；MapLibre 桥接为 Leaflet 缩放减一，因此页面 12 级及以上隐藏这些地名（原为 14 级），独立铁路车站名、道路和水域名称保留。
