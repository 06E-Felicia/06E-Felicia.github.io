# 浏览器本机 / GitHub 后台强对流过程模拟

**无 WRF、无额外计算服务器、无 API key。** 默认以 Pyodide 0.28.3 在浏览器 Worker 逐步运行 Python/NumPy/SciPy 内核；GitHub Actions 可批量运行并存档实验。

## 访客一键模拟

点击「开始模拟」：新 Worker 内生成新的密码学随机主种子；独立参数序列抽取月份、水汽、急流、切变、南支槽、北侧冷空气、海温和持续扰动，再初始化并逐步积分。相同种子与数值设置可用管理员配置复现（跨 Pyodide/原生依赖版本允许浮点差异）。网页不再显示种子、CFL、水量账目、参数调试表或复现按钮；这些仍在代码、计算元数据及测试中保留。

默认 **6 km / 72 h / 每 10 个模拟分钟保存**；可选 4/8/12 km。Worker 先顺序积分完整过程；网页准备期间显示「环境初始化」进度与估计剩余时间，不显示未完成的气象画面或回放控件。进度来自实际积分时长，剩余时间按已运行速度估算，可能随过程改变；初次载入时暂无法估时。开始按钮与数值设置在整轮运行期间锁定，时间流速仍可调整。流速不限制计算。每个状态通过校验并压缩存入本机后才确认下一状态；全部保存、终点时刻匹配后隐藏初始化面板并从头自动播放。

精度默认「保真」，云雨体积场采用双精度；「节省内存」仅将这些体积场存储与输送改为单精度，CAPE 气块诊断仍为双精度。两者保留相同网格、层数和物理机制，但单精度舍入可能使后期非线性演变分岔，不能保证逐格一致。回放间隔可选 10/20/30 分钟；增大间隔减少气块输出诊断、编码、压缩和存档次数，不改变内部物理步长，代价是回放更稀疏。保持真实性优先可保留「保真」，仅调整保存间隔。

完成后自动进入首轮天气演变；首轮结束（或手动结束已就绪的过程）才开放暂停/继续按钮和回看滑条，没有旧实验加载入口。播放速度可切换为每秒 1/5/15/30 个模拟分钟或最快；最快仍逐帧解码显示，不改变物理积分。拖动滑条暂停播放并定位到该实际计算时刻，可从此处继续；播放结束可重新播放。本轮结束后开始新一轮生成新种子，清空上一轮结果；取消计算不播放残缺过程，关闭页面中止计算。6 km / 72 h 的完整计算需要等待，设备性能和本机存储速度决定耗时。

固定版本运行时和科学包已随项目打包在 `assets/vendor/pyodide/`（约 30 MB），运行时只从本站加载，可由浏览器缓存。科学包按上游锁文件校验 SHA-256；维护脚本为 `simulation/vendor_runtime.py`。本轮天气状态以 gzip 压缩存入 IndexedDB，回看时按需解压；内存仅缓存最多两个解码状态，不将整个三维过程留在内存。存储不足会明确停止，不提供伪造的完整过程。观测点导出仅含本轮实际查看到的数据。站点可直接部署为 GitHub Pages 静态网站。

地图以原生气象网格生成 Web Mercator 栅格并缓存，拖动/缩放直接复用栅格，透明度调整不重新计算雷达。多图联动按动画帧合并更新；同级缩放下仅平移已有图层，不再逐帧强制重置底图，中心差控制在一个显示像素以内。缩放时同步动画、保留旧瓦片和同源的低分辨率底图缓存，等待新细节就绪；风箭头、观测点与冷锋改用保留式 SVG，避免缩放清空 Canvas。跟随图的异步事件不反向驱动主图；缩放中切换布局会等待旧地图动画结束再释放，避免回调访问已删除节点。访客地图不绘制冷池轮廓，冷池计算保持不变。只显示现有归档站表中 32 个主要城市代表站（广东 21、广西 11），保留实际站址和站号，城市与代表站名不同会注明；不是完整地级市台站名录。自定义点仍可添加。

地图最小缩放按当前画幅适配华南模拟边界（104.3°–118°E、19.8°–26.7°N）；缩放不能越过该最小值，平移也受同一区域限制。布局切换和窗口尺寸变化会重新计算区域缩小极限，不开放世界尺度视图。

公开图层仅保留合成/单站雷达、径向速度、925/500/300 hPa 风、MUCAPE、气温、格点雨强、近一小时降水和累计降水。点位面板保留气温、露点、风速、风向、雨强、近一小时降水、累计雨量和 MUCAPE 共八项。SBCAPE、MLCAPE、CIN、冷池温差/厚度等仍参与内核计算，不作为地图或观测指标显示。

## 运行与部署

1. 将本项目代码上传至仓库；Settings → Pages → Source 选择 **GitHub Actions**。
2. Actions → **运行强对流模拟** → Run workflow。
3. 选择种子、时长、网格、输出间隔。推荐首次 `8 km / 12 h / 60 min` 检查部署，再运行 `6 km / 72 h`。
4. `calculate` 完成后，`publish` 自动部署网页，计算结果作为实验工件保留。前端仍从用户新开始的过程演算，不加载这些旧结果。
5. 管理员环境参数位于 `simulation/config.json`；网页不提供参数调试或配置导出表单。Actions 中的四个输入会覆盖 JSON 同名设置。`compact_transport` 默认 `false`，可在配置文件中启用省时模式；CLI 也支持 `--compact-transport`。

管理员批量实验工件保留 90 天；仓库/组织设置可能缩短保留期。工件存档不影响访客的新模拟。后台批量运行消耗 GitHub Actions 额度，未设置自动重复运行。

默认网格 **6 km**，支持 **4/6/8 km**。这不是 1 km 模型，也不代表预报精度。为限制下载量与 Pages 工件大小，程序在运行前可能自动加大输出间隔；有效值和请求值均写入 manifest。默认上限：计算 150 分钟、输出 450 MiB。失败不上传、不发布，保留线上已有版本。GitHub 托管机与本机性能不同。

## 实际计算的内容

- 14 个地形跟随层，离地 30 m 到 16.5 km；近地层加密。
- 温度、水汽、云水、雨水逐步输送，CFL 约束内部时间步；低层水平风随大尺度背景、科氏作用、雨冷压力梯度和地形阻力演变。
- 初始南岭冷暖过渡带、独立南支槽/北侧扰动；槽随引导风向东演变。不指定飑线数量、对象速度、路线或抵深时间。
- 地表热/水汽交换、日变化、参考密度下的分层输送、诊断辐合/坡面抬升、对流质量通量闭合、暖雨凝结/转化/沉降/蒸发。
- 初始温度、湿度、持续时空相关扰动、天气尺度扰动使用独立种子流。相同代码/依赖/配置可复现；持续随机扰动并非逐帧白噪声。内部时间步精确命中扰动和气块诊断事件；界面的时间流速不会改变其随机序列或物理步长。
- SBCAPE、最低 100 hPa MLCAPE、最低 300 hPa MUCAPE 和负值 CIN 从实际温湿廓线诊断；包含虚温修正和随温压变化的饱和气块积分。多个正浮力层采用累计正面积策略。MU 气块用近似相当位温选取。
- 925/500/300 hPa 风按对数气压插值；位于地下的压力面不显示。近地风是最低层近似，不标成严格 10 m 诊断。
- 雷达反射率采用雨水的暖雨近似与脱离冰相凝结水的低效率散射近似，径向速度含平均垂直气流以及回波加权的水凝物水平速度和落速；波束使用 4/3 地球半径和沿程 DEM 遮挡。不是双偏振雷达或完整散射模型。

### 冷锋与对流组织修正（2.1）

- 地面示踪物与温湿场采用相同最低层风；冷、暖侧初始风与背景一致，避免统一南风启动造成锋面漂移。
- 低层动量自身平流、冷气团密度压力头与雨冷压力头参与演变；不再仅依赖被动冷气团标记和固定风向恢复。
- 物理尺度平滑地形坡度/密度压力梯度，避免单格地形尖峰触发交错噪声。热泡仅提供有限边界层抬升，不在固定网格累积数小时。
- 虚温一致的 LFC、CIN 抑制和冷池—边界法向低层切变的再触发闭合；切变保留符号，不把迎切变与背切变两侧当成同等有利。
- 对流来源云水作为总云水的子集独立输送，保留其来源记忆；不因移入触发暂时关闭的格点就被瞬间蒸发。雨滴蒸发同时受雨水供应与相对湿度约束；对流从约 1 km 深的来源层取水，逐项扣账。对流云水转雨阈值按质量通量所用的 3.5% 子网格面积折算，不把稀释后的格点均值误当云内浓度。
- 降水沉降单独按薄层 CFL 子步积分，修复每 90 秒最多下降一层、雨水在底层堆积的错误。

这仍是参数化组织机制，不是解析云尺度涡度的模式。RKW 只提供冷池/切变机制依据，不能据此宣称所有华南飑线都已被准确模拟。[Weisman & Rotunno (2004)](https://doi.org/10.1175/1520-0469%282004%29061%3C0361%3AATFSLS%3E2.0.CO%3B2)。

### 暖湿补给与边界再生修正（2.2）

- 温度、冷气团、冷池、低层动量、抬升记忆和对流活动改用 minmod MUSCL / SSP-RK2 输送，内部 CFL 上限降至 0.45，减少一阶输送对阵风锋的过度扩散；水物质仍采用保正、带参考密度闭合的守恒通量。
- 入流从本轮种子产生的外部温湿储库取值，随边界冷气团比例调整冷暖属性，出流自由离开；不会把已变干的边缘空气、已有雨水或旧对流活动循环当作新入流，也不将锋面强制复位到初始纬度。水量日志继续逐步记入入流与出流。
- 近地层加入 Richardson 数限制的相邻层湍流交换，按日变化、海陆和稳定度将地表供给传到边界层内；成对交换不凭空增加水汽。
- 移除对流质量通量重复的水汽扩散：凝结闭合已经从来源层取水，额外的对流扩散会再次处理该储库。保留独立的解析垂直运动交换与边界层混合。
- LFC 在气块自身 LCL 之上的虚温浮力交点插值。高架气块从自身来源高度抬升，并使用自身 CIN，不再统一要求 1200 m 抬升、限制为 50% 活跃度或仅在冷气团内触发；没有足够抬升仍不会释放。
- 现有对流的平流风由正浮力云层的质量与浮力加权求得，缺少正浮力时回退至 850–300 hPa 质量加权风，取代固定 3.2 km 单层风。新单体沿冷池边缘再生仍单独计算，不再额外叠加一个预设传播速度。这是近似引导闭合，不是完整 Corfidi 法，也不解析超级单体偏离平均风的移动。[Corfidi (2003)](https://journals.ametsoc.org/view/journals/wefo/18/6/1520-0434_2003_018_0997_cpampf_2_0_co_2.xml)

### 暖侧入流与组织闭合（3.0）

2.2 将粗网格内上升气块也绑定到冷却后的局地气柱，阵风锋到来后 CAPE 与触发随之消失，难以不断再生新单体。3.0 改为从阵风锋外侧实际暖气柱诊断上升气块（最多 12 km），按低层法向切变、抬升和 CIN 决定再触发。升凝水从该来源柱真实扣除并沉降；多个上升格点共用同一来源柱时先汇总需求，再按可用水汽统一限额，避免重复使用同一储库。

新增随输送、辐合和冷池—切变平衡演变的组织记忆场。组织程度改变上升气流覆盖率（3.5%–17.5%），而不是给飑线指定位置、寿命或路线。背景暖侧近地南风基准从 2 调到 5 m/s，同时平衡北侧初始入流，避免南风加强后锋面无故北退；北侧扰动仍独立推动后续冷锋南下。初始约 1.3 km 高的暖盖从 1.4 调到 2.2 K；减少大范围同时释放 CAPE，并加强真实暖湿入流。来源与接收格点地形差超过 500 m 时禁止这一跨格供给，山地仍通过阻力和抬升参与其他演变。

深层天气尺度冷气团与约 650 m 的雷暴冷池采用分离的动量分量。锋区示踪物由天气尺度流场输送，冷池压梯作用在浅层流场，并随高度指数衰减；最低层仍严格等于近地预报风。这样不会让一个浅层阵风把整个天气尺度锋面推向北方。北侧扰动对深层冷空气独立施加压力驱动与地形阻力。

机制参考为冷池边缘组织与湿静能输送：[Freitas et al. (2024)](https://doi.org/10.1029/2023MS003982)。本实现是独立简化闭合，未照搬论文整套参数化。干燥或切变不利的随机环境仍可能只有短时雷暴；没有强制每个种子都生成同一条长线。

连续追踪按每 30 分钟的实际强回波连通区域进行：≥35 dBZ、格点雨强 ≥5 mm/h、活跃对流、长度 ≥100 km、长宽比 ≥3、冷池 ≥0.5 K。预测上一组件的云层平流位移，允许冷池传播偏移；至少 30% 单元匹配、方向变化 ≤45° 才延续身份。不填补中间消失时次，不把后来重现的另一条线接成原来的长寿命。追踪是实验性结构验收，尚未完成实况个例校准。

### 锋区抬升深度与子网格雷达（3.1）

- 天气尺度锋区辐合、浅层阵风锋辐合分开处理。初始停滞锋的天气尺度辐合不再直接按暖区深对流的抬升深度扩展到整柱；锋区垂直交换随高度更快衰减。高架气块按其来源高度获得实际可用抬升，不能直接使用地面全部抬升量。
- 在稳定冷气团中，以来源高度和 SBCAPE/MUCAPE 比值诊断边界层与高架气块的解耦，限制高架触发所支撑的深层质量通量及组织增长。保留凝结、层状降水和条件满足时的锋面对流；没有按地图纬度禁止成线，也没有强制锋区回波静止。华南锋区雨与暖区雨可有不同触发、组织和传播机制，[相关研究](https://www.sciencedirect.com/science/article/pii/S0169809519302285)是机制背景，不是本模型准确性的认证。
- 新增对流雨水子集与面积加权雨水矩，两者随输送、蒸发、沉降变化；它们不另加一份水量。雨滴漂移后保留其来源面积，不套用落点当前新上升气流的覆盖率。
- 反射率改为对环境雨与子网格对流雨的**线性 Z** 做体积平均，然后换成 dBZ，而不是先摊平雨水浓度再取非线性幂。环境雨不变、强核不再被粗网格过度稀释；没有全图固定增益、手绘强核或凭空增加降水。使用暖雨 Marshall–Palmer 近似，仍不代表冰相强回波或实况雷达校准。[NOAA 的反射率诊断说明](https://www.emc.ncep.noaa.gov/mmb/research/FAQ-meso.html)区分解析与参数化对流反射率；[子网格观测算子研究](https://gmd.copernicus.org/articles/11/3147/2018/)说明不能忽视非线性与子网格差异，其具体卫星雷达算子不是本实现。

当前版本的过程与交互测试见 [验收记录](ACCEPTANCE.md)，不要把旧版本结果当作当前源码的验证结果。

### 密度流、单体更新与下垫面（3.2）

- 冷池不再是固定 650 m 深、按四小时衰减的被动温差。预报冷空气厚度与深度积分虚温亏损，按保正守恒通量输送；蒸发冷却扣除增湿的虚温补偿后形成冷池，热通量与夹卷恢复它。水平压头随实际深度变化，地形对浅层密度流产生阻滞。厚度受约 1.8 km 的降阶闭合限制，不等于解析三维下沉气流。新增冷池深度图层与观测值。
- 冷池边界由积分压头梯度确定。前缘抬升读取边界后邻近冷气团的有效深度，不能误用数值薄尾部的深度；环流速度由浮力积分诊断，不给所有冷池指定同一速度。[RKW 冷池—切变理论](https://doi.org/10.1175/1520-0469%282004%29061%3C0361%3AATFSLS%3E2.0.CO%3B2)提供机制背景，本模型不解析完整涡度预算。
- 增加种子控制的中高层西风与上层急流，并允许其有小幅南北分量。已有单体按浮力云层加权风输送；锋面与冷池按各自浅层流演变，新单体在这些边界重新触发。系统南移不等于把整条回波统一向南平移。图上的 300 hPa 风与实际内核一致，标尺扩为 80 m/s。
- 单体尺度扰动采用约 14 km 空间相关、20 分钟相关时间、每 5 分钟更新的种子流，并随云层风输送。扰动影响实际抬升与上升面积，之后才产生云雨和反射率；不是给雷达图片叠随机纹理。水物质改用 MUSCL/SSP-RK2 守恒输送，减少强核被一阶平流数值扩散摊平。不会将 6 km 结果伪装成 1 km 分辨率。
- 日变化作用在地表热通量、云遮蔽和边界层混合上，夜间低空急流单独增强；日际水汽储库有六小时更新、约一天相关时间的天气尺度随机变化。强迫不直接乘在回波强度上，也不强制所有地点都在午后最强。[华南日变化研究](https://journals.ametsoc.org/view/journals/mwre/149/10/MWR-D-20-0292.1.xml)表明内陆午后与沿海夜晨峰值可由不同机制支撑。
- 春季冷海面只冷却海洋边界层，不把自由大气整柱一同变冷而错误保留大量地面 CAPE。地面耦合活动作为单体活动的来源子集输送，避免地面型单体跨岸后瞬间被重新标成高架单体、跳过稳定层的代价。山脊阻滞读取实际来源层入流在山脊法向的风速，不能用较快的云层移动速度冒充低层补给速度。它们限制深对流补给并加快失去补给的单体衰减；原有雨水继续输送和沉降，不在跨岸时删除像素。迎风触发、强急流或高架不稳定仍可支持新生对流，不能宣称所有水域、山脉都必然消灭风暴。[复杂地形 MCS 观测](https://repository.library.noaa.gov/view/noaa/65086/noaa_65086_DS1.pdf)说明山地既可使母体衰减、阻断冷池，也可在条件适合时支持下游新生。

管理员可运行 `python -m simulation.check_crossings` 检查同种子的理想化暖区单体跨平地、山脊、冷水面的差异。验收实际下游雨强与强回波格点减少，不把触发资格或弱新云数量当作强度。这一测试专门注入有限上升气流与冷池，生产初始化不注入任何预设风暴；测试不是实况校准。

### 计算加速与浅层触发（3.3）

- MUSCL/SSP-RK2 的风面和散度在同一步的多个场之间复用，用切片计算限制通量，减少整卷填充与重构数组。保持原有开边界、minmod、两阶段积分和 CFL 条件。默认双精度模式的早期加速对照与旧实现逐值一致；省时模式则是明确可选的数值精度取舍。
- 气块只在真正跨越 LCL 的气柱做分数层积分，干层不计算随后被丢弃的湿绝热曲线；去掉动力过程未使用的混合层气块重复诊断。输出仍从当前廓线计算 SBCAPE、MLCAPE、MUCAPE 与 CIN。
- 浏览器可选融合输送及 RK4/分数 LCL 内核，直接访问 Pyodide 的 [WASM 缓冲区](https://pyodide.org/en/stable/usage/type-conversions.html#buffers)，不搬运整卷数组到另一个模型。启动时对实际网格短测，只在至少快约 10% 时启用对应后端，否则保留 NumPy。标量、非连续或不支持的精度组合走参考路径。浮点数学库的细微差异仍需允许；内核对照见 `simulation/check_acceleration.py`。
- 独立 Worker 不再在每批积分之间插入零毫秒计时器；界面仍独立响应，取消直接终止 Worker。状态存盘确认继续提供背压，不丢帧、不跳步。Worker 的进度消息只供内部使用，当前网页不展示进度条或剩余时间。
- 浅冷池阵风抬升与天气尺度抬升分别按各自的垂直范围作用于高架来源层。浅密度流不再套用 3.5 km 深暖区的整柱抬升尺度，以免在稳定海面上错误再生高架单体。采用约两倍冷池厚度作为简化垂直衰减尺度，不代表解析压力场或重力波传播。
- 地面耦合旧单体在失去地面不稳定能量时，不能立刻免费改用全部高架 MUCAPE。对流质量通量按来源记忆与实际 SB/MU 能量的差额减少；真正高架的新单体和实际暖侧入流仍可维持。改动作用于产水质量通量，非回波颜色。

日变化与海面削弱尚需进一步实况校准。日夜专项对照现在先实际积分背景到相应时刻，再注入相同的试验扰动，不能直接跳钟却保留同一份 08:00 廓线；不同背景时长也意味着该试验不是纯粹隔离所有天气尺度因素的实况归因。

管理员可用 `python -m simulation.benchmark --hours 1 --grid-km 6 --profile` 定位耗时，加 `--compact-transport` 比较省时模式。浏览器固定种子的顺序计时为 `tests/benchmark_simulation_modes.cjs`；计时须避免并行运行其他重计算任务，不能将不同机器的秒数混为通用加速比。

### 静止锋、飑后层状区与雨强（3.4）

- 在实际冷暖示踪物的 0.5 轮廓附近估算锋面法向平移，避免把冷侧北风本身当成南下速度。停滞锋只保留浅层汇合抬升，并按实际稳定度恢复气块位移；地面气块必须真正到达 LFC，取消旧的提前 300 m 触发；暖侧高架供给也按来源高度与冷池厚度衰减抬升，不能借用全部地面阵风抬升；不会将数小时汇合无条件累积成深对流。真正北侧扰动推进冷锋时，抬升范围可增大；阵风锋再生仍由独立冷池与切变条件决定。
- 新增来自对流云水的脱离凝结水储库：原云水扣除相同质量，冻结/融化计入潜热，输送、升华、1 m/s 缓慢沉降与融化产雨逐步演算。弱回波必须来自实际水凝物，干冷池没有回波。沿冷池边界与上升气流诊断参数化前向后相对输送，保留环境沿线西风，不给飑线写死路线。前向后流与慢落速可形成飑后层状区，但并非所有系统必然具有相同的尾部形态。[BAMEX 层状区研究](https://journals.ametsoc.org/view/journals/mwre/137/4/2008mwr2505.1.xml)、[微物理敏感性研究](https://journals.ametsoc.org/view/journals/mwre/137/3/2008mwr2556.1.xml)。本实现是简化闭合，未经这些观测的逐例校准；虚拟多普勒按线性回波权重组合环境雨、对流核和脱离冰相的水平运动与落速，但不是完整冰粒子散射/测速模型。
- 水汽提取限额改为实际入流越过格点的周转时间，并适当提高组织对流的上升面积与质量通量；多单体共用来源柱仍统一扣账，不能凭空增加水量。雨滴蒸发计入降温导致的饱和量变化，避免一次蒸发越过饱和。雨滴落速不再一律为 6 m/s：按水含量和占据面积诊断 Marshall–Palmer 谱，积分 Atlas 落速关系并修正空气密度；对流和环境雨分别守恒沉降，采用局地落速的独立 CFL。落速诊断仍是单矩近似，不是显式雨滴谱预报。[Atlas et al. (1973)](https://agupubs.onlinelibrary.wiley.com/doi/abs/10.1029/rg011i001p00001)、[雨滴落速观测算子](https://amt.copernicus.org/articles/18/4857/2025/)。
- **格点平均雨强**是整个 4–12 km 格点的通量；内核保留的**对流核心雨强（估计）**由实际对流雨落地通量及同步输送的占据面积矩推算局地核心值，但不再作为公开图层或观测值。格点平均量不能冒充解析到真实站点的降水，不用固定倍数或 20 mm/h 下限制造达标结果。
- **近 1 小时降水**由真实累计降水的 5 分钟历史及边界插值求差，不是当前瞬时雨强乘一小时；它目前仍是格点平均量。局地短时强降水常超过 20 mm/h，但不表示飑线每处或每小时都必然超过这一数值。[中国气象局强降水记录](https://www.cma.gov.cn/zfxxgk/gknr/qxbg/202503/W020250302606211127018.pdf)。

管理员可运行 `python -m simulation.check_front --output /tmp/front-check.json`，在两个无南支槽、无持续随机扰动、关闭太阳加热以隔离锋面汇合的实验背景，以及实际北侧强迫推进的对照中进行 12 小时验收。另保留有日照的对照，允许条件满足时出现暖区线状对流，不能将所有暖区对流都当作静止锋错误。关闭太阳加热只属于机制对照，不是生产规则或真实夜间预报；生产过程保留太阳周期，不注入预设风暴。隔离的静止锋不得生成伪线状系统，同时必须保留锋区弱降水。

### 向北递减的能量限制与暖区补给（3.5）

南支槽不增加纬度宽度掩膜；改用平滑的有效 CAPE 上限 `40 + 3560 / (1 + exp((latitude - 23.3) / 0.4))` J/kg：约 3470（22°N）、2460（23°N）、567（24°N）、90（25°N），往北继续递减。该限制同时作用于深对流触发、上升气流强度、质量通量及公开 MUCAPE。原始 SB/MU 气块积分保留用于来源选择、抑制与地面/高架耦合比，不能把两个能量同时截顶后误判为完全耦合。已有水凝物仍自由输送、沉降，不按纬度擦除回波。上述纬度和数值是本项目的实验约束，不是文献给出的普遍华南 CAPE 气候值；公开 MUCAPE 是受此约束的模式有效能量，原始值在诊断中单独保留。

修复高架供水储库：旧的「来源附近 ±1 km」与「距地面最低 150 hPa」交集会使约 2.2 km 来源层没有任何可提取的水。现按来源层气压 ±150 hPa 和来源附近 ±1 km 取水，周转时间使用该来源层实际风速，质量通量使用来源密度；共用来源柱依旧统一扣账。南风低空急流不再被背景混合意外削去约一半，组织上升覆盖率与凝结转雨闭合也随之调整；没有增加初始整柱水汽或直接放大雨量显示。

北侧扰动从更偏西的位置出发，以较慢相速演变；后续深层北风与压力驱动适当减弱，保持初始南岭锋区平衡，不写死锋面位置或到达时间。稳定冷侧的接收柱与供给柱共同约束深对流；低能量北侧仍保留锋区弱降水。[华南前汛期综述](https://www.jstage.jst.go.jp/article/jmsj/98/1/98_2020-002/_article)、[暖区降水与低空急流](https://journals.ametsoc.org/view/journals/clim/34/21/JCLI-D-21-0121.1.xml)提供机制背景，并未校准本项目的具体参数。

## 必须了解的局限

### 飑后可用能量与核心降水修正（3.6 / 网页 V1）

公开 MUCAPE 为气块能量经向北递减上限、再扣除已消耗部分的有效能量，不是原始气块 CAPE。按实际获准的对流空气质量通量和来源层储库质量计算消耗；水汽仍从真实供给柱扣除，而未解析的稳定化记忆计在实际接收对流的气柱，随低层飑后气流输送。新的 MU 来源层不能抹掉旧记忆。太阳加热与真实地表湿热通量可恢复能量，边界新入流和平流也会更换气团；不设固定禁雷时间，也不禁止真实暖湿补给后的新对流。这是简化 CAPE 调整闭合，不是完整总能量方程。

前缘使用真实暖侧供给柱自己的剩余能量，不额外扣掉冷侧接收柱的债；同时仍受接收纬度能量上限和稳定度约束。这样把前缘持续再生与飑后未经恢复的重复触发分开，而不是把整个飑线一起关掉。

占据面积改为「组织覆盖率 × 活跃度」，质量通量、局地转雨阈值、雨水面积矩及雷达散射统一使用该面积；不再在速度/通量上重复乘活跃度。组织覆盖率参与真实产水，降水仍受来源水汽统一限额，不放大显示值。核心与环境雨水分别估算蒸发：云内核心按有限宽度减慢混合稀释，实际 LCL 以下仍受环境空气蒸发，保留冷池/下沉气流的供给；两部分共用真实饱和容量，蒸发水全部回到水汽并计入冷却。

这些闭合关系和系数属于实验参数，未经过实况校准。机制参考 [ECMWF 湿物理一致性说明](https://www.ecmwf.int/en/newsletter/164/meteorology/major-moist-physics-upgrade-ifs)，并不是该业务模式的移植或等同实现。

界面标题为「强对流模拟器V1」，移除宣传性副标题；当前主页面采用暮紫顶栏、月白面板、淡紫底色和少量樱粉点缀，提高控件和读数的层次与对比度，不改变雷达气象色阶。初始化进度、预计剩余时间、按钮锁定、完整计算后自动演变、结束后回看和主要城市观测保留。首页更新提示使用真实模拟器截图，先于雷暴估测/深圳官方预警显示，每次页面打开仅显示一次；关闭后不会因天气刷新重复打开。

### 主动冷池与前缘连续再生（3.7）

冷池改为主动的有限厚度约化重力层，预报厚度 H、垂直积分虚温亏损 Q 及两个方向的层积分动量。压强通量含 gQH/(2θ₀)，不再只把温差交给背景风搬运，也不在近地风中重复施加同一压强梯度。采用保正 HLL 干湿界面通量、地形静水重构和独立 CFL≤0.4 子步长；蒸发供给、地表湿热恢复、动量交换和夹卷分别记账。即使无背景风，有限冷池也会自行向外扩展；扩展会使其变薄、减弱，不会复制浮力亏损。

数值方案参考 [Audusse 等的静水重构](https://epubs.siam.org/doi/abs/10.1137/S1064827503431090)，但本项目求解的是带可变浮力、源汇和参考上层的降阶冷池，不能直接继承论文对标准浅水系统的全部证明或声称解析了真实三维下沉气流。

耗损记忆在有明显深度的冷池中作为 H×CAPE亏损 的被动示踪量，使用同一套 HLL 厚度质量通量输送，再除以实际冷池深度；无冷池区域仍随近地风平流。不允许背景风与主动冷池错位，把低耗损气柱直接洗进仍存在的冷池并伪装为热力恢复。冷池相对更暖、但仍深厚且明显冷却的气柱也不能作为阵风锋的「新鲜」来源。

前缘只从最多 12 km 外、地形允许的实际暖侧低浮力亏损柱取水和能量，冷池内部高 MUCAPE 不能冒充新鲜入流。环境切变先剔除冷池自身加速造成的浅层风异常，再用有限深度的入流层平均与上方环境风比较；低空急流可改变有利前缘方向，不写死飑线角度。抬升包括有限冷池头部和向上气流的压力功尺度 C²/2，并检查来源层高度和实际 CIN；较浅出流不能无条件释放高架 CAPE。冷池强度与环境切变共同影响组织，不能把更强冷池等同于任意条件下更直、更长寿的线。

机制参考 [Bryan & Rotunno (2014)](https://www2.mmm.ucar.edu/people/rotunno/Papers/Bryan%2BRotunno2014a_JAS.pdf) 和 [华南弓状飑线个例研究](https://journals.ametsoc.org/abstract/journals/atsc/69/4/jas-d-11-0121.1.xml)。实现采用简化闭合，不是论文模式的移植。冷池辐合不再同时作为无限累计的位移和独立阵风抬升重复触发；真正独立的天气尺度上升仍可释放高架不稳定。

组织建立时间改为三次头部翻转时间 3H/(C×balance)，数值限制在 120–900 s；不再要求每个被前缘新扫过的格点都重新等待固定十五分钟。此时间控制真实上升占据面积与质量通量，并非对回波颜色或显示雨强乘系数。

陆面增加 200 kJ/(m² K) 的有效热容量，地表辐射、土壤热交换、感热、潜热和降雨冷却共同决定皮肤温度；脱离凝结水也参与遮光。取消「按晴天地温恢复后再额外加一次日照感热」的双重供热。CAPE 回补只计净正湿焓通量，并要求地表与当前来源层之间有连续的低 Richardson 数混合路径；稳定冷层隔断时不把地表通量立即记给高架 MU 层。没有固定禁雷时长或每步无依据恢复比例。

成熟降水新增雨滴碰并收集云水：使用已有 Marshall–Palmer 谱和 Atlas 落速积分扫掠率，收集效率取实验值 0.8，液相比例随温度递减。对流/环境雨分别收集各自已有云水，保持水量及子集账目；不放大显示雨量，不设强回波或 20 mm/h 下限。

用户提供的雷达图用于验收形态：连续而弯曲、带有单体起伏的强回波前沿，后侧宽阔的中弱回波区。不把图片作为场、轨迹或覆盖模板。3.7 曾增加冷池边界虚线；按用户后续要求，页面 3.8.1 已移除该轮廓，仅保留冷锋开关，不改变冷池物理、回波或降水值。

### 后部层状云雨的物质链（3.8）

修正 3.7 中冰相脱离云水的慢源项与全温度快速转雨相互竞争的问题：低温云水（包括环境云水）先按有限冻结时间进入冰相，液态转雨与雨滴碰并在 −5°C 以下停止、混合相区逐渐减弱；冻结和融化显式计算潜热。冰相按 [Murphy & Koop (2005)](https://rmets.onlinelibrary.wiley.com/doi/pdf/10.1256/qj.04.94) 的冰面饱和水汽压进行有限速率凝华/升华，并扣除/归还实际水汽；没有冰粒或云水的干冷池不会生成回波。冰相增长时间和单一 1 m/s 沉降速度是降阶实验闭合，未解析粒子谱、冰雹及聚合分选。

新形成的冰相携带其来源前缘法向和风暴相对后向流速三个水量加权矩；采用同一冰水通量携带来源比值，并随参考密度闭合、沉降、升华/凝华及融化同步变化。冰水保留二阶 MUSCL/SSP-RK2，来源比值使用一致的一阶迎风通量，避免独立限制器在几乎无水区制造假高速。后向输送不再在原单体活跃度降低时瞬间消失。来源前缘从实际冷池压头及上升区诊断；冷池尚未形成时回退到环境云层与低层入流的风差，不指定地图方向或预画云盾。沿线背景风保留。这是参数化中尺度后向输送，不是求解三维非静力后部环流。

上升气流同时从同一有限供给柱取出凝结水和有限的超环境水汽，在实际云层脱离；两类需求先合并再限制，多接收柱不能重复取水。融化形成的雨水另外保留「层状雨来源子集」，随总雨水一起输送、蒸发与沉降；它不是新增一份水。生产雷达和多普勒仍读取实际雨水/冰水与一致的粒子运动，不对冷池区域加回波底色、亮度增益或雨强下限。

机制依据：[Rutledge & Houze (1987)](https://journals.ametsoc.org/view/journals/atsc/44/18/1520-0469_1987_044_2640_admsot_2_0_co_2.xml) 关于后向输送、冰相落出与层状降水，以及 [Houze (2018)](https://atmos.uw.edu/MG/PDFs/AMS-Monographs18_Houze_100Years-MCS-Research.pdf) 的 MCS 回顾。引用是机制背景，不代表本模型已复制论文方案或通过实况校准。验收同时报告真实冰相柱含量、融化来源地面降水、冷池后侧 10–40 dBZ 层状区覆盖和原有长线/雨量指标，不以单元测试替代整轮形态验收。

这是**降阶、参数化的机制实验模型**，不求解完整三维非静力压力和动量方程，无法声称正确解析超级单体旋转或所有类型的风暴移动。对流由质量通量闭合表示，14 层不能解析真实云内细节。冰相只用单一的脱离凝结水储库、缓慢沉降与融化近似；未实现完整冰相微物理、冰雹和实况同化，参考气压不包含完整天气尺度质量变化。

输送时采用参考密度闭合补偿未解析的垂直质量汇聚，故水量日志中的“外部项”包含开放边界、地表通量和该闭合项。收支残差小仅证明**数值账目一致**，不是对真实大气质量/能量守恒或预报能力的证明。没有完整总能量守恒宣称。模式行为必须经过实况个例校准后才能讨论预报能力。

DEM 为 Mapzen/AWS Terrarium 瓦片采样，源瓦片 zoom 7，随仓库提供 4 km 采样缓存。高程 ≤0 作为近似海面掩膜，不能精确描述海岸、河道与潮汐。卫星底图与计算地形是两种资料；底图不参与计算。关闭山地会保留原来的海陆掩膜。

## 本地复现（与 Actions 相同程序）

```sh
python3 -m venv .venv
.venv/bin/pip install -r simulation/requirements.txt
.venv/bin/python -m unittest discover -s tests -p 'test_physics.py' -v
.venv/bin/python -m unittest discover -s tests -p 'test_coldpool.py' -v
.venv/bin/python -m unittest discover -s tests -p 'test_stratiform.py' -v
.venv/bin/python -m simulation.run --output assets/simulation --grid-km 8 --hours 12
python3 -m http.server 8080 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8080/simulator.html`。输出目录必须为空；程序拒绝覆盖已有实验。测试另用临时输出目录。跨硬件/依赖版本的结果可能存在浮点差异，manifest 记录模型版本、种子流和配置。

## 协议与测试

CLI 工件的 `manifest.json` 指向 SHA-256 校验的 gzip 帧；本机 Worker 直接发送同一字段编码。字段为带 scale/offset 的小端 int16；32767 为缺测。前端逐帧校验并压缩存档，全部完成后从本轮存档解码播放；地图与观测使用同一时次，不读取后台旧实验工件。

- `tests/test_physics.py`：CAPE 参考值、稳定层结、种子复现、持续随机性、移动边界输送误差、外部入流、边界层混合收支、高架来源层、云层引导风、水量账目、输出不改变模型状态。
- `tests/test_coldpool.py`：静风密度流扩展、冷量守恒、干湿界面、静水地形平衡、山脊阻挡、冷池内部供给拒绝、净湿焓/稳定层回补、雨后地温记忆、环境切变/急流方向、压力功与 CIN、碰并水量子集。
- `tests/test_stratiform.py`：冰面饱和参考、无水不造回波、环境/对流云冻结、凝华/升华收支、母单体消散后的后向流记忆、融化雨来源、蒸发子集、云水/水汽共享供给与全步状态。
- `tests/test_simulation_data.cjs`：协议校验、路径安全、量化、网格边界及多普勒符号。
- `tests/test_simulation_v2_browser.cjs`：准备中仅有初始化进度/估时，没有气象画面或回看控件；开始锁定、完成后自动首轮演变、首轮结束后回看、精简图层、同步地图、华南缩小极限、站点、移动端和损坏数据处理。
- `tests/test_simulation_local_browser.cjs`：真实 WASM 内核两轮独立环境、完整计算后自动播放、播放速度切换、压缩回看、立即取消和旧线程隔离。
- `tests/test_simulation_live_process.cjs`：真实 Worker 六小时完整计算、随后播放至终点、降水演变与观测点。
- `python -m simulation.validate --hours 24 --grid-km 6 --seed 20260421 --require-duration-hours 4 --quiet --output /tmp/process-check.json`：连续组件追踪与锋面、雨量、冷池、CAPE、数值水量收支；若持续线状系统未达到四小时则返回失败。
- 加 `--random-environment` 使用与实时页面完全相同的参数抽样；`--snapshots` 另存逐六小时的计算场。可用 `simulation.plot_validation` 做科学 QA 图（额外需要 Matplotlib，网页不需要它）。
- 旧 `simulator-model.js` 等 v1 文件不再被页面加载；旧单体动画测试不是 v2 验收依据。
