# Astra 本机测试启动器

双击项目根目录的 **`development/launchers/复现Astra测试.command`**。启动器校验归档，启动或复用本机 HTTP 预览，并自动打开测试回放；保持终端窗口打开。只需要 Python 3 和浏览器，不需要 NumPy、服务器、API key，也不会重新计算。

已打包两轮真实 Astra：种子 `20261017`、`20260421`，均为内核 `4.15.0-rear-circulation`、12 km / 10 h / 14 层。逐数组复现本轮用户认可的后侧输送结果。打开定位在各轮归档选取的成熟时刻，可切换过程和四种图层、播放、从头播放、拖动回看、点击地图核验格点数值。[本轮说明](REAR_CIRCULATION_2_5.md) 另含 Sol 测试与性能局限。

这些测试当时保存的是每小时快照，故每轮共 11 帧；提供合成雷达、MUCAPE、格点平均雨强和累计雨量。温度、三维风和点位细雨核没有保存在这份 NPZ 中，不在回放里补造。这里只重放已完成结果，不是用新随机参数重跑。公开模拟页面仍保持每次开始全新计算，没有新增加载历史结果入口。

数据存放在 `local-test-results/astra/`（另附 `evidence/` 原始报告和 NPZ），已导出到项目内，不依赖 `/tmp` 或浏览器存储。保留此目录才可复现；它已加入 `.gitignore`，不会随正常 Git 推送发布。迁移到另一台电脑时，应一起复制该目录、启动器和项目文件。归档缺失或校验不符会明确报错，不会静默换一轮天气。

此前归档分别保留在 `local-test-results/astra-v4.11/`、`astra-v4.12/`、`astra-v4.13/`、`astra-v4.14.0/`、`astra-v4.14.1/`、`astra-v4.14.2/`，没有删除；默认启动器读取本轮 4.15.0。`evidence/` 中保留本轮原始报告、NPZ、回归日志及 Sol 浏览器计算报告（五分钟性能门槛未通过），方便核验源码与逐时结果。

底图需要联网；离线可选“无底图”，实际雷达和雨量仍能回放。页面只允许本机地址，不能用 `file://` 直接打开，也不是 GitHub Pages 的公开功能。

仅校验：`python3 -m simulation.test_replay --check`。

维护者在下一轮测试结束后，可用科学计算环境运行 `python -m simulation.export_test_replay <Astra测试JSON> ... --output <新的空目录>` 导出；它读取对应 `.json.npz`，不重算物理。默认目录不得覆盖已有归档，以免误删本轮结果。

核验：四项标准库测试通过，真实 Chrome 检查启动器、两轮加载、逐值读取、首屏成熟时刻、播放/回看、无 Worker 计算、篡改归档拒绝均通过。
