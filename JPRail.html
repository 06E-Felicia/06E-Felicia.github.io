ABOUT THIS ATLAS

数据、范围与使用方式

本页主要收录外国游客用铁路 Pass，另按用户要求增列不限国籍的青春18车票。纯地铁、纯巴士券、普通单程票及其他普通一日券不在目录范围内。部分外国护照产品也允许在日外国人购买，资格以每款说明为准。

客运参考线与车站来自国土交通省 2025 年底 N02 数据，已简化以便浏览。详细铁路设施在线加载 OpenRailwayMap，包含其已收录的货运、专用线、车辆基地与停用线。新建、停运或缺失设施可能存在更新延迟。

高亮属于范围示意。适用区间按所列来源匹配至参考线路，位置与轨迹仍有示意误差；未核实条目另行标明。每次仅选择一张 Pass。线路筛选与 Pass 独立使用：开始筛选会退出 Pass，选择 Pass 也会清除线路筛选。运营方可多选叠加，并与等级、都市圈取交集。地理上连通，不表示可以持该 Pass 连续乘车；新干线、特急、付费座席、直通第三部门与进出次数另有条件。

概览中的深色双圈表示主要枢纽或区域大站；放大至近距离后恢复普通站点符号，并逐步显示小站名。底图始终隐藏日本国名，放大到区域近距离后隐藏城市名、保留车站名。蓝色菱形表示公司运营局界，无论是否属于所选 Pass 边界均可显示；绿色边界圈只表示所选 Pass 的真实适用边界。主要站符号不会把普通换乘站变成票券边界。

点击“全部线路”可清除 Pass 与线路筛选，恢复初始全国取景。电脑可用滚轮小幅缩放，Mac 触控板可用双指捏合缩放。手机选择 Pass 后，详情位于地图下方，可单独滚动或关闭。

普通铁路采用本页整理的公司配色：JR 普速橙黄色、新干线红色，私铁参考公司标识，东京及近郊部分私铁为便于辨识另作显示色调整；黑白标识公司另采用官方线路图、铁路服务页或注明来源的地图参考色，非统一官方色值规范。公司筛选只针对普通铁路和新干线；地铁、路面电车、单轨、新交通系统和钢索缆车保留原显示方式，不新增公司配色。页面采用不含铁路的地理底图。选择Pass或筛选后，匹配范围保留原色，其余线路采用浅灰、60%不透明度作位置参考；灰色不表示车票适用。详细设施原图仅在无选择、无筛选时可开启。线路筛选按正式路名分为新干线、本线、地方／其他 JR 线及私铁线，不是 JR 票价制度的干线／地方交通线。本线归组合并同名 JR 区段与已转交的对应区段，保留现运营方和颜色；不补画已撤除或缺失的轨道。都市圈不将新干线列为彩色匹配，但保留浅灰参考和车站资料，按本页注明的中心车站及半径选取范围内的完整站间区段，着色在车站收尾，非官方行政区、通勤圈或票券边界。无筛选时仍可查看原有全部设施种类。
